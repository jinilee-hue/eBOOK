## 핵심 알고리즘

### `fitDown()` — 폰트 자동 맞춤
운율 쪽은 46px, 그 외 30px에서 시작해 1px씩 내리며 `scrollHeight > clientHeight`가 해소될 때까지 반복. **하한 18px.** 최대 80회.

### `buildBeats()` — 쪽 자동 분할
18px에서도 넘치면 마지막 문장을 다음 구간으로 밀어내고 다시 시도. 문장 중간에서 자르지 않는다. 반환값은 읽기 구간 배열이고, 컨트롤 바의 점 개수가 여기서 나온다.

**재실행 시점**: 쪽 전환 / 서체·명암 변경 / 접기·펴기 완료 후(470ms) / 문제 상태 전환 후(450ms) / resize / orientationchange(300ms 지연)

**접힘 상태 예외**: `#body`의 `clientHeight`가 0이면 계산을 건너뛰고 `true`를 반환한다. 안 그러면 무한 축소가 일어난다.

## 상태와 전환

### 본문 패널 — `#app[data-read]`

| 상태 | 동작 |
|---|---|
| `on` | 그리드 `1fr 46%`. 버튼 문구 "책 접기" |
| `off` | 그리드 `1fr 0`, 패널 `opacity:0` + `translateX(24px)`, `pointer-events:none`. 문구 "책 펴기" |

전환 `.45s cubic-bezier(.22,1,.36,1)`. 접힘은 쪽을 넘겨도 유지된다. 접힌 채로도 읽어주기와 문제 흐름이 끊기지 않아야 한다 — 컨트롤 바가 패널 밖에 있는 이유다.

### 문제 띠 — `#app[data-q]`

| 상태 | 표시 | 진입 조건 |
|---|---|---|
| `hidden` | `max-height:0`, `opacity:0`, 테두리 없음 | 쪽 진입 시 기본 |
| `ask` | 질문 + "눌러서 보기 ▾" 만. 보기·다음 숨김. 띠 전체가 클릭 대상 | 마지막 구간을 다 읽고 `다 읽었어요` |
| `open` | 보기 4개 노출, 화살표 180° 회전, 큐 텍스트 흐려짐 | `ask` 상태에서 띠 클릭 |

전환 `max-height .42s cubic-bezier(.22,1,.36,1)`. 보기는 50ms 간격 stagger로 `translateY(10px) → 0`.

### `다 읽었어요` 버튼 — `#go`

| 상태 | 표시 | 해제 조건 |
|---|---|---|
| `wait` | 회색, `opacity:.45`, 클릭 불가, "읽는 중…" | — |
| 활성 | 파랑. 마지막 구간이면 "다 읽었어요", 아니면 "계속 읽기 ▸" | 읽어주기 종료, 또는 `speechSynthesis` 미지원 시 즉시 |

**`speechSynthesis`가 없거나 실패하면 반드시 즉시 해제할 것.** 안 하면 진행이 막힌다.

### 보기 선택

| 결과 | 동작 |
|---|---|
| 정답 | 초록 테두리 + 배경, 키 원형이 초록으로. `다음 쪽` 활성화 |
| 오답 | `shake .35s`, 400ms 뒤 클래스 제거. **오답 표시를 남기지 않는다** — 다시 시도할 수 있어야 한다 |

정답을 맞히기 전에는 다음 쪽으로 넘어갈 수 없다.

## 모달

`role="dialog"`, `aria-modal="true"`. 열림 시 `scale(.94) translateY(10px) → none`, `.28s`.

| 모드 | 구성 |
|---|---|
| 낱말 | 단어 42px + 발음 버튼 / 한국어 뜻 / 구분선 / "이야기 속에서" 원문(해당 단어 `<mark>`) + 한국어 / 단어장 담기 + 닫기 |
| 문장 | 원문 21px + 듣기 버튼 / 한국어 뜻 / 닫기 (단어장·문맥 블록 숨김) |

열자마자 해당 단어·문장을 한 번 자동으로 읽어준다. **읽어주기 중이면 먼저 중단한다** — 두 음성이 겹치면 아무것도 안 들린다.

닫기: 닫기 버튼 / scrim 클릭 / Esc.

단어장에 담으면 본문의 해당 단어가 `.saved`로 바뀌고 상단 카운터가 오른다. 같은 단어가 여러 곳에 있으면 전부 갱신한다.

## 엣지 케이스

- **한 문장이 혼자서도 18px에 안 들어갈 때** — 현재는 그대로 둔다. 원문 최장 문장(13쪽 마지막)이 46% 폭에서 들어가는 것을 확인했으나, 세로 모드나 1024 기기에서 재확인 필요. 그래도 넘치면 그 쪽만 `content/pages.js`에서 문장을 나눌 것
- **폰트 로드 실패** — 폴백이 `sans-serif`라 자간이 달라지고 맞춤 계산이 틀어진다. `document.fonts.ready` 이후에 첫 `buildBeats()`를 돌릴 것
- **mp4 없음** — 절차적 씬으로 폴백. 콘솔 경고만, 사용자에게는 아무 표시도 하지 않는다
- **TTS 음성 없음** — `voiceschanged`를 기다리되 1.2초 타임아웃. 그래도 없으면 읽어주기 버튼을 숨기고 `#go`를 즉시 활성화
- **빠른 연속 탭** — 쪽 전환 중 `다음 쪽` 재클릭 방지. `#next.disabled`로 이미 막혀 있으나 전환 애니메이션 중에도 유지할 것

## 접근성

- 터치 타깃 최소 44px. 현재 `#play` 40px → **44px로 올릴 것**
- 단어 점선 영역이 작다. `padding: 2px 0` → 상하 여백을 늘려 탭 영역 확보
- 포커스 링이 현재 없다. `:focus-visible`로 `--act` 2px 아웃라인 추가
- 진행 점(`.pill`)에 `aria-label="16쪽 중 3쪽"` 같은 텍스트 대체 제공
- `prefers-reduced-motion`: 배경 drift, 보기 stagger, 그리드 전환, 모달 스케일 모두 중단 (프로토타입에 이미 있음)
- 색만으로 정답을 전달하지 않는다 — 현재 초록 테두리 + 배경 + 키 원형 반전 3중이라 충족
